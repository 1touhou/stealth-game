**Lamplight — The Quiet Gallery**: a top-down stealth heist in a night museum. Slip past four patrolling guards, steal the Sun Disk, the Jade Fox and the Moon Harp, then escape through the green exit — unseen. Guards sweep vision cones along routes you can learn, grow suspicious when they glimpse you, investigate, chase, and search; shadows hide you, crates and display cases block their sight, and a tossed pebble pulls a guard away. WASD/arrows to move, Shift to run (loud), C to sneak, E to toss a pebble, F to grab a relic, click to walk there, P to pause, M to mute. All art and sound are original and generated in code; the soundtrack is synthesized live with WebAudio.

## Run it

```sh
python3 -m http.server 8000 --directory game
# open http://localhost:8000
```
